# W05 — Wake, objective, and activation lifecycle

W05 extends the PostgreSQL operational authority with durable objectives, wakes,
activation leases, an idempotent command ledger, and append-only lifecycle
history. Wake responsibility commits before notification; a missing in-memory
signal therefore remains discoverable and is delivered at least once.

Objectives follow the governing state machine and cannot become SATISFIED
without an explicitly accepted completion claim. Activation leasing records UTC
expiry and a monotonic start value, rejects clocks beyond the configured trust
bound, and uses transactional row locking. Bootstrap recovery classifies expired
leases before release; interrupted effect waits require reconciliation.

Run nix run .#test-w05 -- --evidence-dir PATH. Qualification uses digest-pinned
PostgreSQL 17, injects notification loss and a database process kill, and emits
wake-crash-matrix, lease-recovery-report, and objective-transition-report.
