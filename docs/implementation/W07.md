# W07 — Context compiler and semantic request broker

W07 implements an immutable, content-addressed context boundary in `habitat-context`.
Every item carries a truth class, source/version provenance, observation and compilation
times, and a freshness deadline. Compilation is deterministic and records budget-driven
omissions together with resulting uncertainty.

Context faults use semantic requests: callers state the deficiency, materiality,
requested information kind, and resolution condition without naming an internal source.
The broker enforces source allowlists, freshness, and recursion depth, then emits a new
bundle linked to both its predecessor and the resolved request. Consequential summaries
may expose only bounded, expiring access to their original evidence.

External content is always represented as `UntrustedExternalData`. Directive-shaped
payloads produce a security observation but remain inert data; they cannot replace the
typed activation or objective identity.

Run the qualification gate with:

```console
nix run .#test-w07 -- --evidence-dir ./w07-evidence
```

The gate emits `context-conformance-suite.json`, `context-fault-test.json`, and
`injection-defense-test.json`.
