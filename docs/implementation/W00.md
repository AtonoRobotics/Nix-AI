# W00 — Contract foundation

## Current scope

Issue #18 implements W00.1: import the governing v1.1 bundle unchanged and expose
the locked contract-development and validation environment. It does not claim the
remaining W00 schema, Protobuf generation, traceability, or qualification work.

## Governing requirements

- BLD-001 — Faithful implementation
- BLD-002 — Reproducible public interface
- BLD-004 — Packet evidence
- BLD-009 — No implicit policy
- BLD-010 — Production continuity
- W00 contract and manifest requirements in `contracts/work-packets.yaml`

## Components and files

- Immutable source: `Habitat-OS-Codex-Build-Bundle-v1.1/`
- Byte-identical projections: `CODEX-BUILD-SPEC.md`, `contracts/architecture/`,
  `contracts/proto/`, `contracts/schemas/`, and the root contract registries
- Locked environment: `flake.nix`, `flake.lock`
- Validation entry point: `tools/validate_contracts.py`

## Boundaries and compatibility

The validator treats any source-manifest failure or projected-byte difference as a
hard failure. This bootstrap introduces no runtime authority, migrations, ABI, or
compatibility policy.

## Tests and evidence

- `nix run .#validate-contracts`
- `nix flake check --show-trace`
- A clean-checkout run is required before W00 itself may be marked passed.

## Rollback and blockers

Rollback removes only the bootstrap projections, flake, and validation wrapper;
the immutable source bundle remains the recovery source. No W00.1 blocker is known.
The rest of W00 remains tracked by Issues #19–#22.
