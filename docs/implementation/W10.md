# W10 — Capability package controller

W10 adds `habitat-packages`, a signed package admission and immutable activation-set
controller. Publisher trust uses Ed25519 verification. Admission rejects untrusted,
revoked, incorrectly signed, mutable, or supply-chain-incomplete packages and never
implicitly grants provider or agent authority.

Dependency resolution closes exact capability versions and verifies hardware,
isolation, state-schema, and artifact requirements. A provider becomes active only
after a behavioral capability probe. The resulting activation set is content-addressed
and records exact artifact and configuration digests, state schemas, grants, and
verification evidence.

Replacement stops new binding while existing activations retain their pinned set.
Drain, emergency revocation, migration evidence, recovery wakes, and exact rollback are
explicit operations. In-process lifecycle hooks are restricted to local registration and cleanup; they
cannot represent external effects, durable package admission, or OS rollback.

Run `nix run .#test-w10 -- --evidence-dir ./w10-evidence` to emit lifecycle,
pin-and-drain, rollback, system-conformance, and architecture-boundary reports.
