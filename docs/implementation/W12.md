# W12 — Omniverse and Isaac provider

`habitat-simulation` is the authority-preserving compatibility boundary for RTX and Isaac Sim workloads.
It admits only digest-pinned vendor capsules whose GPU model, driver, memory requirement, and feature set match
the selected hardware profile. Admission exposes only mediated NVIDIA device nodes and no ambient environment.

Simulation operations require an explicit capability grant and authority decision. Successful operations return
stable, typed, digest-addressed effects; replaying an idempotency key returns the original effect. GPU access is
bound to a single activation lease and disappears when that lease is released.

Qualification produces `rtx-isaac-live-report`, `simulation-effect-report`, and `gpu-isolation-report`. On builders
without an NVIDIA device, the live hardware observation is truthfully declared absent while provider-contract
conformance remains exercised. Hardware-profile release qualification must run the same probe on the target GPU host.
