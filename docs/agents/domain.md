# Domain docs

This repository uses a single-context domain-document layout.

Before exploring or changing the project, read:

- `CONTEXT.md`, when present
- relevant ADRs under `docs/adr/`

Missing domain documents are created lazily when terminology or durable
architectural decisions are resolved. Their absence is not an error.

Use the vocabulary defined in `CONTEXT.md`. Surface any conflict with an
existing ADR rather than silently overriding it.
