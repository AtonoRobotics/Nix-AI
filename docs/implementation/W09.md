# W09 — Direct model driver

W09 adds `habitat-models`, a provider-neutral frontier-model boundary with adapters for
OpenAI Responses and Anthropic Messages. Both adapters translate only an explicit
`submit_disposition` function/tool call into the same semantic ABI disposition. Plain
text, provider stop, malformed JSON, missing command identity, and invisible capability
requests cannot become actions or completion.

Activation inputs contain immutable identity and references plus visible capability
descriptors; they contain no provider credentials. No provider transport or credential
module is retained in the cognition core; external effects remain behind current authority
and effect admission. Protected evidence retains
provider/model/request identifiers, token usage, latency, activation and trace
correlation, and a request digest while excluding credentials, prompt content, and
hidden reasoning.

Run `nix run .#test-w09 -- --evidence-dir ./w09-evidence` to produce the structured
disposition, provider replacement, credential isolation, telemetry correlation, and
protected audit reports.
