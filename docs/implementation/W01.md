# W01 — Nix image and hardware-profile framework

## Governing requirements

ARC-001, BLD-002, BLD-003, BLD-008, GEN-001–GEN-009, HWP-001–HWP-003,
HWP-006–HWP-008.

## Components and files

- `nix/modules/habitat-image.nix`: immutable image, bootstrap, serial protocol,
  mutable-path boundaries, and systemd-boot policy.
- `nix/profiles/qemu-x86_64-conformance.nix`: truthful reference profile.
- `nix/images/`: QEMU, raw, installer, and recovery builders.
- `tools/test_w01.py`: live UEFI boot, persistence, and boot-count rollback tests.
- `evidence/work-packets/W01/`: digest-addressed packet evidence.

## Compatibility and authority boundaries

W01 introduces no runtime Agent ABI implementation. Missing final-runtime
services force `PRE_OPERATIONAL` and prevent final Habitat confirmation. Build,
evaluation, boot selection, and evidence are separate operations. Operational
state lives outside immutable closures and is never rolled back with software.

The QEMU conformance profile declares KVM, TPM, GPU, device passthrough,
thermal telemetry, vendor capsules, and domain-specific features absent. Those features
must not be inferred from emulation.

## Tests and evidence

- Public flake image builds and `nix flake check --show-trace`.
- `apps.x86_64-linux.test-boot`: UEFI boot, identity, truthful readiness, power cycle,
  durable history, no prompt/emergency shell/secret leakage, writable-path audit.
- `apps.x86_64-linux.test-rollback`: boot-counted candidate, withheld blessing, automatic
  baseline selection, and persistent operational-state proof.
- Exit evidence: `qemu-boot-report`, `generation-identity-report`, and
  `defective-boot-rollback-report`.

## Rollback and blockers

Rollback selects the exact retained baseline/recovery boot entry. Image changes
are removed by reverting W01 outputs; W00 qualification remains independent.
No contract blocker is known. KVM absence affects speed only because TCG executes
the same live QEMU boundary.
