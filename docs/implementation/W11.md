# W11 — Harness adapters

W11 adds `habitat-harnesses`, optional Codex CLI and Claude Code cognition backends over
the same semantic ABI as the direct model driver. Each adapter receives a bounded,
immutable activation envelope and emits only an explicitly structured disposition.
Harness prose, session completion, process exit, or lack of a tool call cannot complete
an objective or trigger an effect.

Durable identity, objectives, grants, context, effect history, completion contract, and
activation-set pin remain Habitat-owned. Private transcripts are deliberately discarded;
only validated dispositions and typed checkpoints can become durable records. Harnesses
receive no ambient credentials or unrestricted network/device access and may invoke only
explicitly granted Habitat capability endpoints.

The prepared activation records exact adapter artifact and configuration digests.
Cancellation and deadline expiry are classified while committed progress and effect
uncertainty remain intact.

Run `nix run .#test-w11 -- --evidence-dir ./w11-evidence` to emit the cross-backend
conformance and same-agent identity reports.
