# W08 — Effect service and reconciliation

W08 adds `habitat-effects`, a durable effect ledger implementing atomic admission,
stable semantic idempotency, provider attempts, independent observation, ambiguous
outcomes, and reconciliation. Provider contracts declare their reconciliation mode
and maximum consequence class; non-reconcilable providers cannot admit E2–E3 work.

Transport loss after dispatch records `OUTCOME_UNKNOWN`. Reconciliation changes that
same effect rather than creating or blindly retrying another effect. Every attempt
retains its request digest, dispatch time, provider, transport identifier, response,
observation source, and terminal classification.

Cancellation before dispatch terminates a reservation; after dispatch it preserves
ambiguity. Compensation creates a separately admitted effect linked to the original,
so compensation failure cannot erase original success. Declared ordering, restart
recovery, generic execution constraints and validity windows, and objective completion
coupling all fail closed.

Run `nix run .#test-w08 -- --evidence-dir ./w08-evidence` to emit the required
canonical `effect-report.json`.
